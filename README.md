# 三角洲口琴便捷工具 v11

> **v11：Accessible & Ethical 风格重设计 + 换曲同步修复 + 暂停按钮 + 添加曲谱入口**
> — 全面采用高对比度无障碍设计风格；修复换曲时悬浮窗谱子不同步的 bug；新增暂停/继续按钮和添加曲谱入口。

## 项目架构

```
harmonica-visualizer/
├── harmonica_visualizer.py   # 入口
├── run.bat                   # 启动脚本
├── src/
│   ├── constants.py          # 按键映射、配色、面板布局
│   ├── config.py             # 配置读写（防抖）、路径、示例曲谱
│   ├── song_parser.py        # 曲谱解析（简谱 + Dr-hydra）
│   ├── winapi.py             # Win32 VK 映射、强制置顶
│   ├── utils.py              # 绘制工具
│   ├── overlay.py            # 悬浮窗（渲染 + 输入轮询 + 演奏逻辑）
│   ├── panel.py              # 面板（曲谱列表 + 热键按钮）
│   ├── sub_panel.py          # 小面板（倍速/方块长度）
│   ├── editor.py             # 曲谱编辑器（录音/编辑/导入导出）
│   ├── midi_import.py        # MIDI 导入
│   ├── main_window.py        # 主窗口（曲库 + 控制 + 工具 + 设置）
│   ├── settings_dialog.py    # 设置对话框（热键/外观/演奏）
│   └── main.py               # 入口：组装模块、selftest
├── tests/
│   ├── test_song_parser.py   # 34 个用例
│   └── test_midi_import.py   # 26 个用例
├── docs/
│   └── 使用说明.txt
├── scripts/
│   ├── HarmonicaScore.spec   # PyInstaller 瘦身配置
│   └── 重新打包exe.bat
├── songs/                    # 曲谱文件夹
└── config.json               # 运行时生成
```

## v11 新功能

| 功能 | 说明 |
|------|------|
| Accessible & Ethical 风格 | 全面采用高对比度无障碍设计：浅色背景 + 深蓝主色 + 大号字体 + 黄色焦点环 + 大触控目标 |
| 换曲谱子同步修复 | 修复主窗口选曲/上下首时悬浮窗谱子不更新的 bug |
| 暂停按钮 | 演奏组新增暂停/继续按钮，跟随模式下精准暂停不丢进度 |
| 添加曲谱入口 | 工具组新增「添加曲谱」按钮，选择 .txt 文件一键加入曲库 |
| 更大的字体 | 正文 15px、标题 22px，比旧版提升约 15%，可读性更强 |
| 清晰焦点环 | 所有可交互元素均有 2px 黄色焦点环，键盘导航一目了然 |

## 音符颜色

| 颜色 | 音调 | 操作 |
|------|------|------|
| 白 | 本音 | 不按鼠标 |
| 绿 | 降调 | 长按鼠标左键 |
| 紫 | 半音 | 长按鼠标中键 |
| 蓝 | 升调 | 长按鼠标右键 |
| 黄 | 半音+降调 | 中键+左键 |
| 红 | 半音+升调 | 中键+右键 |

## 启动

```
python harmonica_visualizer.py
python harmonica_visualizer.py --selftest
python -m pytest tests/ -v
```

## 热键

| 热键 | 功能 |
|------|------|
| Shift+F3 | 保存曲谱 |
| Shift+F5 | 切换经典/跟随 |
| Shift+F6 | 显示/隐藏悬浮窗 |
| Shift+F7 | 下一首 |
| Shift+F8 | 调整模式 |
| Shift+F9 | 从头重来 |
| Shift+F10 | 面板穿透 |
| Shift+F11 | 曲谱编辑器 |
| Shift+F12 | 录音 |
| Shift+↑/↓ | 倍速/方块±10% |
| Ctrl+Alt+Q | 退出 |

## 曲谱格式

```
TITLE=小星星
BPM=90
1 1 5 5 6 6 5 - | 4 4 3 3 2 2 1 -
b3 #5 ^1 8 - 0
```

## 安全说明

不安装钩子、不模拟按键、不读写游戏内存、不注入、不联网。只用 GetAsyncKeyState 读键鼠状态 + 画置顶窗口。

## 打包

```
python -m PyInstaller --noconfirm scripts/HarmonicaScore.spec
```

瘦身配置，约 24 MB 单文件。
