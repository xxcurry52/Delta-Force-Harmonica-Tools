三角洲口琴便捷工具  使用说明 v11
================================

【启动】
双击"三角洲口琴便捷工具.exe"，打开后显示主窗口。
点「显示悬浮窗」或按 Shift+F6 弹出游戏内叠加层。

杀毒软件报警 → 选"允许运行"。Windows 蓝色提示 → 点"更多信息"→"仍要运行"。

★ 游戏设为「无边框窗口」或「窗口化」，独占全屏会盖住悬浮窗。
★ 建议右键 exe →「以管理员身份运行」。
★ 悬浮窗每 2 秒自动强制置顶，游戏全屏也不会被覆盖。

----------------------------------------------------------------
【v11 新功能】

1. Accessible & Ethical 风格
   全面升级为高对比度无障碍设计：
   · 浅色背景 + 深蓝主色，清晰不刺眼
   · 字体更大（正文 15px、标题 22px），可读性更强
   · 黄色焦点环，键盘导航一目了然
   · 更大的按钮，更容易点击

2. 换曲谱子同步修复
   主窗口选曲、上下首切换时，悬浮窗谱子同步更新。

3. 暂停按钮
   演奏组新增「暂停」按钮，跟随模式下精准暂停，
   点继续从暂停处无缝接着走，不丢进度。

4. 添加曲谱入口
   工具组新增「添加曲谱」按钮，选择 .txt 曲谱文件，
   一键复制到曲库并自动刷新列表。

曲库：点一下选中，双击直接演奏。
演奏：选模式 → 开始演奏。
  从头重来 = 重新开始。
  暂停 = 暂停/继续演奏（跟随模式下精准暂停）。
速度/长度：拖滑块即时生效。
  倍速 = 跟随模式调速（20%-200%）
  方块 = 经典模式方块长短（50%-200%）
  透明 = 悬浮窗整体透明度（20%-100%）
  背景 = 悬浮窗背景深浅（100-255）
工具：
  录音 = 进游戏弹一遍自动生成曲谱
  添加曲谱 = 选择 .txt 文件加入曲库
  曲谱编辑器 = 编辑/导入/MIDI 转曲谱
  保存曲谱 = 保存当前曲谱到曲库
  调整悬浮窗 = 悬浮窗进入调整模式（全窗口拖动）
  面板穿透 = 切换面板鼠标穿透
  设置 = 热键/外观/演奏参数

----------------------------------------------------------------
【第一次使用：对齐按键】

1. 进游戏掏出口琴，画面下方显示 8 个琴键
2. 主窗口点「显示悬浮窗」
3. 拖悬浮窗顶部拖拽条，移到游戏口琴正上方
4. 拖边框缩放，让 8 条通道对准游戏 8 个按键
5. 判定线贴在琴键上沿
6. 位置自动保存，下次启动恢复

----------------------------------------------------------------
【两种模式】

经典模式（默认）：
  音符块从下往上堆叠，最底部的块（黄色高亮边）= 现在要弹的音
  按对 → 块消失，整叠下落。按错 → 闪红。弹完显示"完成"。

跟随模式（音游式）：
  音符按节奏从上方下落，到判定线时弹。
  弹第一个音 → 3 秒倒计时 → 开始。按对消除，按错变暗。
  倍速在主窗口调。暂停按钮可随时暂停/继续。

----------------------------------------------------------------
【音符颜色 = 鼠标修饰键】

白色 = 不按鼠标（本音）
绿色 = 长按鼠标左键（降调）
紫色 = 长按鼠标中键（半音）
蓝色 = 长按鼠标右键（升调）
黄色 = 中键+左键（半音+降调）
红色 = 中键+右键（半音+升调）

----------------------------------------------------------------
【快捷键】（均可在设置中自定义）

Shift+F5   切换经典/跟随
Shift+F6   显示/隐藏悬浮窗
Shift+F7   下一首
Shift+F8   调整模式
Shift+F9   从头重来
Shift+F10  面板穿透
Shift+F11  曲谱编辑器
Shift+F12  开始/停止录音
Shift+F3   保存曲谱
Shift+↑   倍速/方块+10%
Shift+↓   倍速/方块-10%
Ctrl+Alt+Q 退出

----------------------------------------------------------------
【曲谱格式】

默认在 songs/ 文件夹，一个 txt = 一首曲子。

写法：
  1 2 3 4 5 6 7 8  → z x c v b n m , 各 1 拍
  -                → 延长 1 拍
  b 前缀 = 降调  # = 半音  ^ = 升调
  #b = 半音+降调  #^ = 半音+升调
  0 = 休止符  | = 小节线  // = 注释
  文件头可写 BPM=90 和 TITLE=曲名

添加曲谱：
  主窗口 → 工具 → 添加曲谱 → 选择 .txt 文件 → 自动加入曲库

----------------------------------------------------------------
【MIDI 导入】

曲谱编辑器 → 导入 MIDI → 选 .mid 文件，自动转换为曲谱。
音高映射：C 大调 do-si+高音 do 对应 8 个键。

----------------------------------------------------------------
【安全说明】

不安装钩子、不模拟按键、不读写游戏内存、不注入、不联网。
只用 GetAsyncKeyState 读键鼠状态 + 画一个置顶窗口。
