130 秒上手

  1. 右键 三角洲口琴曲谱.exe → 以管理员身份运行（绿色免安装，无需 Python）
  2. 游戏请用 无边框窗口 / 窗口化 显示，独占全屏会盖住悬浮窗
  3. 按 Shift+F8，用鼠标把窗口拖到游戏口琴按键正上方，再按一次锁定
  4. 按 Shift+F9 从头开始，看着最下面那块弹
第一次运行的两个提示（正常现象）：
• 杀毒软件可能误报 — 程序只做两件事：画置顶窗口 + 读键鼠状态，不联网、不读内存、不模拟按键。选择"允许运行"即可。
• Windows 蓝色保护窗口 — 点"更多信息" → "仍要运行"（未签名 exe 都会这样提示）。

3两种演奏模式

按 Shift+F5 切换，面板也有按钮。

经典模式 堆叠消除（默认）

音符块全部从下往上堆叠，最下面带白色描边的那块就是当前要弹的音：

  • 按对 → 块变半透明 + "按住中"效果，松手才真正消失，整叠下落一层
  • 按错 → 该通道闪红光，音符不消失，重新按对的键即可
  • 全部弹完显示"演奏完成"，1 秒后自动从头开始
长音按住多久块就留多久，不会手还没松、块就飞了。想退回旧行为（按下即消失），把 config.json 的 leader_hold_until_release 改成 false。

跟随演奏 音符按节奏下落（像音游）

音符按真实时值从上方落下，落到窗口底部灯带（判定线）的那一刻就是该弹的时刻：

  1. 切到跟随模式后不立刻开始 — 显示"弹对第一个音「x」开始"
  2. 按对第一个音 → 3 秒倒计时 → 音符开始下落
  3. 每个音都要按住不放才算完成：按下只算"接住了"，判定线把块一点点吃掉，整块吃光才算弹完
  4. 中途松手 → 剩下那截变暗漏过（松开 0.2 秒内又按回来不算断）
  5. 同一个键连着好几个音时，一直按着不放就行，会自动接上
倍速调节：Shift+↑ 加快 / Shift+↓ 减慢（每次 10%，范围 20%~200%），也可点面板下方小面板的 +/− 按钮。
小面板自动切换：跟随模式 → 显示"跟随倍速"；经典/录音模式 → 显示"方块长度"（Shift+↑ 拉长 / Shift+↓ 缩短，50%~200%，只改长短不改宽度）。

4快捷键速查

所有 F 区快捷键都要按住 Shift 再按（防止与游戏 F4~F12 冲突）。面板每个按钮右边也写着对应快捷键，不想背就点按钮。
快捷键功能
Shift+F5切换 经典 / 跟随演奏 模式
Shift+F6一键隐藏 / 恢复全部窗口（游戏里临时让开视野）
Shift+F7换下一首曲子
Shift+F8调整位置（拖动 / 缩放），再按一次锁定
Shift+F9从头重来
Shift+F10面板鼠标穿透（点不动了按它恢复）
Shift+F11打开曲谱编辑器（添加 / 编辑曲谱）
Shift+F12开始 / 结束录音
Shift+F3静默保存曲谱（游戏在前台也能按）
Shift+↑跟随=倍速+10%；经典=方块长度+10%
Shift+↓跟随=倍速-10%；经典=方块长度-10%
Ctrl+Alt+Q退出程序
不想按 Shift？用记事本打开 config.json，把 hotkeys 里的 "shift+" 删掉即可退回单键。

5首次对齐（只需一次，位置自动记住）

  1. 进游戏，掏出口琴，画面下方显示 8 个琴键
  2. 点面板【调整窗口】或按 Shift+F8 — 窗口变金黄虚线框
  3. 拖动窗口到琴键正上方，拖边缘/四角缩放，让 8 条竖线与 8 个按键一一对齐
  4. 关键：把窗口底部的"灯带"细横线贴在游戏琴键区上沿
  5. 再按一次 Shift+F8 锁定 — 位置和大小自动存入 config.json
窗口最小约 420×360，保证面板内容不被挤压。下次启动自动在原位。

6曲谱管理

默认在程序旁边的 songs 文件夹，一个 .txt = 一首曲子。启动时自动读取全部 txt。手动丢 txt 进去也能识别。

换曲谱文件夹

  • 按 Shift+F11 打开曲谱编辑器
  • 点【曲谱文件夹…】→ 选目录 → 曲谱就从那里读写了
  • 点【打开文件夹】→ 直接弹出资源管理器
  • 换回默认：再点【曲谱文件夹…】选回程序旁边的 songs

曲谱格式（简谱，很直白）

写法含义
1 2 3 4 5 6 7 8八个音，对应 z x c v b n m , 各占 1 拍
数字后加 -延长 1 拍（例：5 - - = 5 弹 3 拍）
b 加在数字前降调（例：b5）
# 加在数字前半音（例：#2）
^ 加在数字前升调（例：^1）
0休止符（停一拍）
|小节线（装饰用）
文件开头可写 TITLE=曲名 和 BPM=90（BPM 当前版本用不到）。
也自动支持 Dr-hydra 曲谱库格式（带节奏标注，配合跟随模式体验最佳）。

7自己录曲谱（弹一遍就会）

不用打字、不用懂格式：自己弹一遍，程序帮你记下来。

  1. 点面板【添加曲谱】或按 Shift+F11，弹出编辑器窗口
  2. 最上面填曲名
  3. 点【● 开始录音】或按 Shift+F12 — 窗口出现红点和"录音中"
  4. 进游戏，掏出琴，把曲子按顺序弹一遍（白音直接按键，高音按住右键+按键，以此类推）
  5. 弹完按 Shift+F12 结束录音
  6. 直接按 Shift+F3（游戏前台也能按）— 曲谱存好，曲名默认"我的曲谱"
  7. 想改名/检查：按 Shift+F11 打开编辑器，文本框里可修改，按错了点【撤销一个音】（Ctrl+Z）
  8. 点【保存到曲谱库】或 Ctrl+S — 曲谱出现在面板列表，直接能弹
按住键不松、只切鼠标键也算一个新音（V9.3）：比如 1 #1 1，可以按住 z 不放、按一下中键再松开，程序照样记成三个音。

9常见问题

Q: 按某个键没反应？

看面板"输入检测"行：显示了"检测到：X" → 程序读到了，只是不是当前该按的键；什么都没显示 → 键没被监听，检查 config.json 的 note_keys。

Q: 切到游戏里窗口就消失了？

几乎不是程序坏了，是 Windows 画面合成被绕过。按顺序排查：

  1. 游戏显示模式改「无边框窗口」（改完重启游戏！）
  2. Win11：设置 → 系统 → 屏幕 → 显示卡 → 关掉「窗口化游戏优化」+「自动 HDR」
  3. 游戏 exe → 属性 → 兼容性 → 勾「禁用全屏优化」
  4. 双屏/双显卡：把游戏和程序拉到同一显示器，都设为「高性能」
  5. 关掉系统 HDR 试试
  6. 关掉 MPO（多平面叠加）：注册表 HKLM\SOFTWARE\Microsoft\Windows\Dwm 新建 DWORD OverlayTestMode=5，重启电脑
快速定位：切到游戏后连按两次 Shift+F6。窗口回来了 → 只是被顶到下面，调环境即可；还是不出现 → 画面合成被绕过，只能改系统/游戏设置。

Q: 录完按 Ctrl+S 没保存？

Ctrl+S 只有编辑器窗口在最前面才生效。最省事：直接按 Shift+F3（游戏前台也能按）。

Q: 快捷键和游戏冲突？

不会。程序只"看一眼你按了什么"，不拦按键。所有 F 区快捷键都要求按住 Shift，游戏里直接按 F4~F12 时本程序完全无反应。

Q: 面板挡住游戏点击了？

右边音符区永远鼠标穿透。面板挡到的话按 Shift+F10 让面板也穿透。
